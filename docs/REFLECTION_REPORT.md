# AI Usage Reflection Report

## 1. Which AI tools were used and how?

ChatGPT was used during the development of the Equipment Lending Portal. It helped in planning the project structure, designing the React frontend, creating the Java Spring Boot backend structure, preparing API documentation, and resolving Git-related issues.

## 2. Example prompts used

Some example prompts used were:

- Create a GitHub repository structure for React and Spring Boot project.
- Create a responsive React frontend for an equipment lending portal.
- Add role-based login for student, staff, and admin.
- Create Spring Boot backend with H2 database and 200 dummy records.
- Help me push the project to GitHub.

## 3. Parts generated by AI vs manually coded

AI helped generate boilerplate code, folder structure suggestions, sample REST APIs, dummy data generation logic, and documentation drafts.

Manual work included creating the project locally, running commands, reviewing the generated code, fixing integration issues, testing the application flow, pushing to GitHub, and preparing the final demonstration.

## 4. Did AI help or hinder understanding?

AI helped speed up development by suggesting a clear structure and reducing time spent on boilerplate code. It also helped explain errors step by step. However, the AI output still needed manual review and testing because generated code may not always match the local environment or exact project requirements.

## 5. Issues encountered while integrating AI output

Some issues encountered were:

- Vite latest version required a newer Node.js version.
- GitHub repository already existed, so push was rejected until remote changes were pulled.
- Frontend initially used localStorage data before backend integration.
- Field names had to be adjusted between frontend and backend.

## 6. What was learned from debugging AI-generated code?

I learned that AI-generated code should not be copied blindly. It is important to understand the folder structure, dependencies, API contracts, and database mappings. Debugging helped me understand React routing, role-based UI, Spring Boot layers, REST API design, CORS configuration, and Git workflow better.

## Conclusion

AI was helpful as a development assistant, but the final responsibility of understanding, testing, and integrating the application remained with me. The project improved my understanding of full-stack development using React and Java Spring Boot.
